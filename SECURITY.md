# Reporting a security issue

Please report suspected vulnerabilities privately to the repository maintainers or an Aelyx-Work organization owner through your approved company communication channel. Include the affected repository, a concise description, and steps to reproduce when safe.

Do not publish exploit details, credentials, customer data, or proof-of-concept code in a public issue or pull request. Give maintainers a reasonable opportunity to investigate and coordinate a fix before any public disclosure.

If a repository enables GitHub private vulnerability reporting, use its Security tab to submit the report there.
